6. 로그 백업 및 정리 스크립트

6-1. 스크립트 실행

sudo python3 backup_manager.py 실행 결과: 로그 파일을 tar.gz으로 압축 백업하고, 30일이 경과한 백업 파일은 자동 삭제한 다.

6-2. 코드 주요 내용

내부 라이브러리 임포트

import os import tarfile import time from datetime import datetime

변수 설정

target_dir = './.workspace/log' # 백업할 로그 디렉토리 backup_dir = './backup_store' # 백업 저장 디렉토리 retention_days = 30 # 보관 기간 (일)

오늘 날짜로 백업 파일명 생성 (%Y: 연도, %m: 월, %d: 일)

today = datetime.now().strftime('%Y%m%d') backup_file = f'backup_{today}.tar.gz'

tar.gz으로 압축 백업

with tarfile.open(backup_path, 'w:gz') as tar: tar.add(target_dir)

30일 경과 파일 삭제

retention_days * 86400 (1일 = 86400초) 기준

실제 운용 서버에서는 로그 파일이 지속적으로 생성되어 디스크 용량을 차지한다. 법적으 로 로그 보관 의무가 있는 기업은 보관 기간을 별도로 설정하여 운용해야 한다.

  • 가상 환경 없이 패키지를 설치·삭제하면 실제 우분
  • 투 운영체제에 영향을 줄 수 있다
  • 가상 환경을 사용하면 각 환경이 독립적으로 동작하므로, 다른 환경에 영향을 미치지 않
  • 는다.
2-2. 가상 환경 디렉토리 구조

가상 환경 생성 후 디렉토리 구조는 다음과 같다. ~/ └── python_practice/ # 실습 디렉토리 └── venv/ # 가상 환경 디렉토리 ├── bin/ # 실행 파일 (python3, python3.12, pip, pip3, pip3.12) └── lib/ # 라이브러리 저장소 bin/ 디렉토리: 파이썬 실행 명령어 위치 lib/ 디렉토리: 설치된 라이브러리 파일 저장
