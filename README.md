# SKT ALEPH 학습 노트

SKT ALEPH **IT 인프라 · 보안 과정**의 수업 노트를 책 한 권으로 엮은 저장소입니다.
수업이 진행되는 대로 장을 추가합니다.

## 지금 들어 있는 것

| 부 | 장 | 분량 |
|---|---|---:|
| 들어가기 | 이 책의 사용법 · 커리큘럼 지도 | 10,299자 |
| 1부 네트워크 | 라우팅 · ACL · NAT · VPN (Packet Tracer) | 37,049자 |
| 2부 리눅스 서버 | Rocky Linux 9 서버랩 · NFS/Samba/SELinux/rsyslog · 메모리/커널/계정/Kali | 255,026자 |
| 3부 데이터베이스 | MariaDB SQL·백업·복제 · 팀 웹과 원격 MariaDB 연동 | 115,485자 |
| 부록 | 중복과 상충 정리 · 명령어 색인 · 용어집 | 13,488자 |

합계 **43만자 · 소제목 729개**.

커리큘럼 전체는 배포 슬라이드 **188강** 기준이며, 그중 노트로 정리된 구간과 아직
제목만 있는 구간을 「커리큘럼 지도」에 표시해 두었습니다.
가장 큰 미작성 구간은 **보안 실습·모의해킹 74강**입니다.

## 읽는 법

```bash
python build.py          # site/ 아래에 HTML 생성
# site/index.html 을 브라우저로 엽니다
```

빌드 결과는 **장마다 별도 HTML**입니다. 처음에는 한 파일로 합쳤으나
43만자·1.1MB가 되어 브라우저가 렌더링하지 못했습니다(실측). 그래서 나눴습니다.

화면 구성:

- 왼쪽 사이드바 — 전체 장 목록 + **현재 장의 소제목**, 목차 검색, 읽는 위치 자동 표시
- 본문 — 세리프 본문, 코드 강조, 표 가로 스크롤, 라이트/다크 자동
- 아래 — 이전 장 / 다음 장 이동
- 인쇄하면 사이드바와 이동 버튼이 빠지고 본문만 나옵니다

## 폴더 구조

```
notes/        수업 노트 원본 (이 책의 본문)
book/         목차·지도·부록 등 연결 자료
curriculum/   배포 슬라이드 188강 원본 목록
build.py      notes + book -> site/*.html 조립
make_index.py 부록 「명령어 색인」 자동 생성
site/         빌드 결과
```

**같은 내용을 두 곳에 두지 않습니다.** `notes/`가 원본이고 책은 조립 결과입니다.
노트를 고치고 다시 빌드하면 그대로 반영됩니다.

## 수업이 끝날 때마다 하는 일

```bash
# 1) 새 노트를 notes/ 에 넣는다   (파일명: 2026-09-01_주제.md)
# 2) build.py 의 ORDER 목록에 한 줄 추가한다
# 3) make_index.py 의 NOTE_LABEL 에 짧은 이름을 추가한다 (색인 표기용)
python build.py
```

`build.py`가 자동으로 처리하는 것:

- 첫 `#` 제목을 장 제목으로 올리고 나머지 제목 단계를 한 칸씩 내림
- 한글을 살린 앵커 id 생성, 장 안에서 중복되면 번호를 붙임
- 사이드바 목차 · 이전/다음 이동 · 인쇄 배치
- 부록 명령어 색인 **재생성** (손으로 고치지 마십시오)

## 노트를 쓸 때의 규칙

원본 노트가 이미 쓰고 있는 표기를 그대로 유지합니다.

| 표시 | 뜻 |
|---|---|
| ✅ | 실제로 실행하고 출력까지 확인한 것 |
| ⚠️ | 실제로 발생한 오류, 빠지기 쉬운 함정 |
| 📘 | 수업에서 안 다뤘지만 이해에 필요해 공식 문서에서 보강한 것 |
| ★ | 자주 틀리는 지점 |

**출처가 불확실하면 적지 않습니다.** 기억으로 채우지 않고 "확인 필요"로 남깁니다.
