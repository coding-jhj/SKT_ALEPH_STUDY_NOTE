## 어떻게 읽나

- **왼쪽 사이드바** — 전체 장 목록. 지금 보는 장은 소제목까지 펼쳐집니다. 검색창에 단어를 넣으면 목차가 걸러집니다

- **아래** — 이전 장 / 다음 장
- **인쇄** — 사이드바와 이동 버튼이 빠지고 본문만 나옵니다. PDF로 저장하면 그대로 교재가 됩니다

장이 28개로 나뉘어 있는 이유: 한 파일로 합치면 117만자·1MB가 넘어 브라우저가
렌더링하지 못합니다(실측). 그래서 장마다 별도 HTML입니다.

# 만드는 쪽

여기서부터는 이 저장소를 고칠 사람을 위한 내용입니다. 읽기만 할 거라면 위 링크로 충분합니다.

## 폴더

```
notes/        수업 노트 원본 — 사람이 직접 쓴 마크다운
slides/       핵심키워드 188강 — PDF에서 자동 추출 (손으로 고치지 마십시오)
book/         사용법·커리큘럼 지도·부록
curriculum/   배포 슬라이드 188강 원본 목록

build.py      notes + slides + book  ->  docs/*.html
import_slides.py  핵심키워드 PDF zip  ->  slides/*.md
pdf_blocks.py     PDF 한 쪽을 제목·본문·코드·표로 나누는 부분
make_index.py     부록 「명령어 색인」 자동 생성

docs/         빌드 결과. GitHub Pages가 이 폴더를 그대로 서비스합니다
```

**같은 내용을 두 곳에 두지 않습니다.** `notes/`와 `slides/`가 원본이고
`docs/`는 조립 결과입니다. 원본을 고치고 다시 빌드하면 반영됩니다.

## 빌드

```bash
python build.py
```

`docs/`가 다시 만들어집니다. 로컬에서 확인하려면:

```bash
python -m http.server 8899 --bind 127.0.0.1 --directory docs
# http://127.0.0.1:8899
```

푸시하면 GitHub Pages가 1분 안에 반영합니다.

## 수업이 끝날 때마다

```bash
# 1) 새 노트를 notes/ 에 넣는다        파일명: 2026-09-01_주제.md
# 2) build.py 의 ORDER 목록에 한 줄 추가
# 3) make_index.py 의 NOTE_LABEL 에 짧은 이름 추가   (색인 표기용)
python build.py && git add -A && git commit -m "9/1 수업 노트 추가" && git push
```

`build.py`가 알아서 하는 것:

- 첫 `#` 제목을 장 제목으로 올리고 나머지 제목 단계를 한 칸씩 내림
- 한글을 살린 앵커 id 생성, 장 안에서 중복되면 번호를 붙임
- 사이드바 목차 · 이전/다음 이동 · 인쇄 배치
- 부록 명령어 색인 재생성 (손으로 고치지 마십시오)
- **본문에 적힌 HTML 태그를 전부 글자로 막음** — 노트에 XSS 실습 페이로드가
  실려 있어서, 막지 않으면 노트를 여는 순간 그 스크립트가 실행됩니다

## 슬라이드 원문 다시 가져오기

```bash
python import_slides.py "<핵심키워드 zip 경로>"
python build.py
```

PDF는 글자의 위치만 담고 있어 무엇이 제목이고 무엇이 코드인지 표시가 없습니다.
이 꾸러미는 **글자 크기가 곧 구조**라서 그것으로 복원합니다.

| 크기 | 정체 | 결과 |
|---|---|---|
| 30pt | 쪽마다 반복되는 문서 제목 | 버림 |
| 18pt | 대제목 `1. ...` | `###` |
| 15pt | 소제목 `1-1. ...` | `####` |
| 12pt | 본문 | 문단 |
| 8~9pt DejaVuSansMono | 터미널 화면 | ` ``` ` 코드블록 |
| 7.5pt | 머리말·쪽번호 | 버림 |

표는 `find_tables(strategy="lines_strict")`로 찾습니다. 기본값 `lines`는 칸을
그린 선이 아니라 글자 배치까지 선으로 쳐서, 4열 5행 표를 6열 7행으로 깨뜨립니다.

줄바꿈은 문서 전체에서 만든 낱말 사전으로 복원합니다. 붙여 만든 낱말이 문서
어딘가에 온전히 나오면 붙이고, 아니면 공백을 넣습니다.
