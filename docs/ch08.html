CHAPTER 11

vi·프로토콜·Windows IIS

8.27보강내용.pdf(제작: 강성록)를 옮긴 것입니다. 원본이 이미지 PDF라 페이지를 렌더링해 읽고 정리했습니다. 다룬 질문은 "vi편집기, http, https, ftp, ftps, dns, window 웹 서버가 궁금합니다"였습니다.

1. vi 편집기

vi 편집기란?

  • 빌 조이가 1976년에 개발한 Unix 계열 운영체제의 문서 편집기
  • Visual editor라는 의미

상태 전환 구조

        VI 시작                     VI 종료
           │                           ▲
           ▼                           │ ZZ
  ┌──────────┐   ESC   ┌──────────┐  i a  ┌──────────┐
  │ 콜론 모드 │ ◀────── │ 명령 모드 │ ─────▶│ 입력 모드 │
  │  · 저장   │   :     │ · 커서 이동│ ◀───── │ 입력한 내용이│
  │  · 종료   │ ──────▶ │ · 줄·글자  │  ESC  │ 버퍼로 옮겨져│
  └──────────┘         │   삭제·복사│       │ 추가 및 삭제│
   :q  :q!  :w  :wq    └──────────┘       └──────────┘

vi [options] file 로 실행합니다.

세 가지 상태

명령 상태 - 커서 이동, 수정/삭제, 복사/붙여넣기, 탐색 실행 - vi 실행 직후의 상태 - 입력 상태에서 ESC키를 누르면 명령 상태로 전환 - i, a, o, c 키를 누르면 입력 상태로 전환

입력 상태 / 편집 상태 / insert mode - 글씨를 입력하는 등의 편집이 가능한 상태 - 명령 상태에서 i, a, o, c 키를 누르면 입력 상태로 전환 - ESC키를 누르면 명령 상태로 전환 - 전환 시 하단에 --INSERT-- 표기

설정 상태 - 저장, 종료, 탐색, 치환 및 vi 환경 설정 등을 수행하는 상태 - 명령 상태에서 : 키를 누르면 설정 상태로 전환

각 상태 별 명령어의 종류와 쓰임새는 따로 공부. 명령어 표는 「과정 개요」의 vi 편집기 절에 정리돼 있습니다.

2. 각종 프로토콜

http

  • 웹 페이지의 정보를 주고 받는 통신 프로토콜
  • 80번 포트
  • 요청/응답의 구조

https

  • 보안이 추가된 웹 페이지의 정보를 주고 받는 통신 프로토콜
  • 443번 포트

ftp

  • 파일을 주고 받는 통신 프로토콜
  • 21번 포트
  • 요청/응답 구조

ftps

  • 보안이 추가된 파일 전송 프로토콜
  • 명시적(Explicit): 일반 연결 후 보안 요청 — 21번 포트
  • 암시적(Implicit): 시작하자마자 보안을 적용 — 990번 포트

dns

  • 도메인을 IP주소로 바꾸는 프로토콜
  • 53번 포트

원본에는 ftps 설명이 "보안이 추가된 웹 페이지의 정보를 주고 받는 통신 프로토콜"로 적혀 있습니다. https 설명이 그대로 남은 것으로 보입니다. 파일 전송이 맞습니다.

3. Windows Web Server (IIS)

네트워크 관리사 2급 실기의 IIS 문제를 푼다면 완벽하게 이해 가능. 한국정보통신자격협회 자료실 페이지 참고 — https://www.icqa.or.kr/cn/board/dataroom

IIS란?

  • 윈도우즈에서 제공하는 무료 활성화 가능한 웹 서버 기능
  • 모듈형 구조와 유연한 아키텍처를 제공

관리자 화면 구성

IIS 관리자를 열면 선택한 사이트에 대해 세 묶음의 설정 아이콘이 나옵니다.

묶음 항목
ASP.NET .NET 권한 부여 규칙, .NET 사용자, .NET 신뢰 수준, .NET 역할, .NET 오류 페이지, .NET 전역화, .NET 컴파일, .NET 프로필, SMTP 전자 메일, 공급자, 세션 상태, 연결 문자열, 응용 프로그램 설정, 컴퓨터 키, 페이지 및 컨트롤
IIS ASP, HTTP 응답 헤더, IP 주소 및 도메인 제한, ISAPI 필터, MIME 형식, SSL 설정, 기본 문서, 디렉터리 검색, 로깅, 모듈, 압축, 오류 페이지, 요청 필터링, 인증, 처리기 매핑, 출력 캐시
관리 구성 편집기

트리 구조는 서버(ICQAServer) → 응용 프로그램 풀 / 사이트 → Default Web Site, ICQA 입니다.

실습 흐름

① IP 로컬 설정 — 「로컬 영역 연결 속성」에서 Internet Protocol Version 4 (TCP/IPv4) 를 선택해 주소를 지정합니다. 연결 항목에는 Microsoft Networks용 클라이언트, QoS 패킷 스케줄러, Microsoft 네트워크용 파일 및 프린터 공유, IPv6/IPv4, Link-Layer Topology Discovery Mapper I/O Driver, Link-Layer Topology Discovery Responder 가 있습니다.

② 사이트 추가 — 「웹 사이트 추가」 대화상자에서 다음을 지정합니다.

항목 실습 입력값
사이트 이름 ICQA
응용 프로그램 풀 DefaultAppPool
콘텐츠 디렉터리 실제 경로 D:\web
바인딩 종류 http
IP 주소 211.111.144.240
포트 8080
호스트 이름 http://www.icqa.or.kr
웹 사이트 즉시 시작 체크

⚠️ 호스트 이름 칸에는 스킴(http://) 없이 도메인만 넣는 것이 정상입니다 (대화상자 예시도 www.contoso.com 형식). 실습 화면에는 http://www.icqa.or.kr로 입력돼 있는데, 자격 시험 답안 형식을 따른 것인지 확인이 필요합니다.

기존 Default Web Site는 ID 1, 상태 시작됨(http), 바인딩 * on :80 (http), 경로 %SystemDrive%\... 로 잡혀 있습니다. 새 사이트를 8080으로 올려 포트 충돌을 피합니다.
