3. OSI 7계층 (ISO-OSI 표준 모델)

OSI 7 Layer 기능
Application (응용-7계층) 사용자 인터페이스 제공 (사용자층의 인터넷 서비스 지원 등)
Presentation (표현-6계층) 데이터의 의미와 표현 방법 (암호화, 압축 등)
Session (세션-5계층) 통신 연결 관리 (토큰 제어, 동기화 등)
Transport (전송-4계층) 단대단(End to End) 통신 기능 (흐름 제어 등)
Network (네트워크-3계층) 라우팅 문제 해결 (최적 경로 설정, 혼잡 제어 등)
Data Link (데이터링크-2계층) 물리적 전송 오류 해결 (전송 기능, 흐름 제어 등)
Physical (물리-1계층) 전송 매체의 물리적 인터페이스 사항 (데이터의 전송 속도, 클록 동기화, 물리적 연결 형태 등)

계층 묶음과 데이터 흐름:

  • Upper Layer (사용자 지원) — 7·6·5계층
  • Transport Layer (전송) — 4계층
  • Lower Layer (네트워크 지원) — 3·2·1계층

보내는 쪽은 위에서 아래로 내려가며 Encapsulation(캡슐화), 받는 쪽은 아래에서 위로 올라가며 De-encapsulation(역 캡슐화) 합니다. 물리 구간(Physical Link)에서 실제로 오갑니다.

8. 네트워크 실습 — 기본 설정 명령어

CISCO Packet Tracer 파일이 함께 제공되었습니다.

Router>enable
Router#configure terminal
Enter configuration commands, one per line.  End with CNTL/Z.
Router(config)#hostname MyRouter                     ← 장비이름 설정
MyRouter(config)#enable password 1234                ← enable 명령어 입력 시 비밀번호 적용
MyRouter(config)#enable secret 12345                 ← secret 패스워드 우선 적용
MyRouter(config)#service password-encryption         ← 설정된 모든 패스워드 암호화
MyRouter(config)#banner motd #Welcome To MyRouter#   ← 부팅 시 메시지 표시
MyRouter(config)#interface giga0/0
MyRouter(config-if)#ip address 192.168.100.254 255.255.255.0
MyRouter(config-if)#no shutdown                      ← 인터페이스에 IP주소 설정 및 활성화
MyRouter(config-if)#
%LINK-5-CHANGED: Interface GigabitEthernet0/0, changed state to up

MyRouter(config-if)#exit
MyRouter(config)#line console 0
MyRouter(config-line)#login
% Login disabled on line 0, until 'password' is set
MyRouter(config-line)#password 12345
MyRouter(config-line)#exit
MyRouter(config)#line vty 0 5                        ← 콘솔/원격접속 시 암호 설정
MyRouter(config-line)#password 12345                 ← Aux 포트로 접속 시 -> #line aux 0
MyRouter(config-line)#login
MyRouter(config-line)#

읽을 점 두 가지입니다.

  • enable password와 enable secret을 둘 다 설정하면 secret이 우선 적용됩니다.
  • login을 먼저 치면 % Login disabled ... until 'password' is set이 나옵니다. 비밀번호를 정한 뒤에야 로그인이 켜집니다.

11. 스태틱 라우팅

네트워크 관리자가 직접 목적지 별로 경로를 지정해 주는 것을 의미합니다.

장점 - Router CPU상에 부담이 없으며, 대역폭을 낭비하는 일이 없다. - 보안성이 있다.

단점 - Router가 어떻게 연결되어 있는지 정확히 알고 있어야 한다. - 한 회선이 추가될 경우 추가된 경로를 모든 Router들한테 설정을 해주어야 하며, 네트워크 규모가 커지면 설정 및 관리가 복잡하다. - 네트워크 변화를 제대로 반영하지 못한다.

Router(config)# ip route [Destination-network] [Destination-mask]
                         [next-hop-address | exitinterface] [Administrative-distance]
인자 뜻
Destination-network 목적지 네트워크를 지정함
Destination-mask 목적지 서브넷 마스크
Next-hop-address 목적지로 갈 수 있는 경로를 지정함 (다음 Router의 Serial Interface의 IP Address)
Exitinterface 목적지에 도착을 하기 위해서 사용되는 Interface
Administrative-distance 거리의 값 지정

Dynamic Routing은 RIP / EIGRP / OSPF 등입니다.

12. ACL — 표준

ACL(Access Control List)은 접속 제어 목록을 통해 패킷을 제어하기 위해 사용하는 일반적인 라우터 보안 설정입니다.

Router(config)#access-list access-list-number {permit | deny} source [mask]
  • Access-list-number : Entry가 속할 list 번호 설정. 1~99, 1300~1999 사이의 번호가 들어간다
  • permit | deny | remark 는 해당 Entry에 매치되면 취할 Action을 정의
  • Source 는 송신지 IP Address를 정의한다
  • mask 는 Wildcard mask를 사용하여 Address 필드의 어느 비트들이 일치되어야 하는지 설정한다
Router(config-if)#ip access-group access-list-number {in | out}
  • List를 적용할 Interface에서 설정한다
  • Inbound 또는 Outbound시 검사하도록 설정한다
  • Default = outbound
  • Interface에서 no ip access-group access-list-number 명령을 사용하여 적용된 Access-list를 제거한다

13. ACL — 확장

Router(config)#access-list access-list-number
  {permit | deny} protocol source source-wildcard [operator port]
  destination destination-wildcard [operator port] [established] [log]
  • Access-list-number : Entry가 속할 list 번호 설정. 100~199, 2000~2699 사이의 번호가 들어간다
  • permit | deny | remark 는 해당 Entry에 매치되면 취할 Action을 정의
  • Source와 Destination 은 송수신지 IP Address를 정의한다
  • mask 는 Wildcard mask를 사용하여 Address 필드의 어느 비트들이 일치되어야 하는지 설정한다
  • Operator port 는 lt(less then), gt(greater than), eq(equal to), neq(not equal to)와 Protocol Port번호를 명시한다
  • established 는 Inbound TCP에 대해서만 사용된다
  • log 는 Console로 log Message를 보낸다
Router(config-if)#ip access-group access-list-number {in | out}

14. NAT — 동적(Dynamic)

① IP 변환에 사용할 전역 주소풀을 설정한다

Router(config)#ip nat pool name start-ip end-ip {netmask Netmask | prefix-length Prefix-length}

② 내부에서 IP변환을 허용할 주소를 Standard Access-list로 정의한다

Router(config)#access-list number permit source-address [wildcard-mask]

③ 동적 변환을 수립하기 위한 NAT 설정을 한다

Router(config)#ip nat inside source list Access-list-number pool name [overload]

④ 각 인터페이스로 이동 후 내부와 외부를 각각 설정한다

Router(config-if)#ip nat inside
Router(config-if)#ip nat outside

overload를 붙이면 포트까지 써서 공인 주소 하나를 여러 사설 주소가 공유합니다(PAT).

15. NAT — 정적(Static)

내부 서버(192.168.100.5/24)를 공인 주소(210.123.94.10)에 고정으로 매핑하는 구성입니다. 내부 스위치 — 라우터 E0(내부) / S0(외부) — ISP 로 이어집니다.

정적 변환을 수립하기 위한 NAT 설정을 한다

Router(config)#ip nat inside source Static local-ip global-ip

각 인터페이스로 이동 후 내부와 외부를 각각 설정한다

Router(config-if)#ip nat inside
Router(config-if)#ip nat outside

18. 리눅스 파일과 디렉터리 구조

경로 이름 설명
/ 루트 최상위(루트) 디렉터리 (절대 경로를 표기할 때 이 디렉터리로부터 시작함)
/bin 바이너리 이진파일(실행파일) / 기본적인 명령어가 저장된 디렉터리 (자주 사용하는 mv, cp, rm 등과 같은 명령어들이 여기에 존재함)
/boot 부트 리눅스의 부트로더(Boot loader)가 있는 디렉터리
/dev 디브(디바이스) 시스템 디바이스(device)파일을 저장하고 있는 디렉터리 (/dev/sda(하드디스크), /dev/cdrom(CD-ROM) 등과 같은 장치 파일들이 여기에 위치함)
/etc 설정파일들 두는 디렉터리
/home 홈 사용자의 홈디렉터리 (사용자를 추가하면 사용자의 id와 동일한 디렉터리가 자동으로 생성)
/lib 립(라이브러리) 커널이 필요로 하는 각종 라이브러리 파일, 커널 모듈파일 등이 존재하는 디렉터리
/media 미디어 DVD, CD-ROM, USB 등의 탈부착 가능한 장치들의 마운트 포인트로 사용하는 디렉터리
/mnt 마운트 탈부착 가능한 장치들에 대한 마운트 포인트로 사용하는 디렉터리
/opt 옵트 응용프로그램 패키지 설치 장소로 패키지 매니저가 자체적으로 설치 및 삭제를 수행함
/proc 프록(프로세스) '가상파일시스템'으로 현재 메모리에 존재하는 작업들이 파일 형태로 존재하는 곳
/root 루트 관리자계정 root 사용자의 홈디렉터리
/sbin 시스템 바이너리 시스템 이진파일(실행파일) (ifconfig, ethtool, halt, e2fsck와 같은 시스템 명령어들을 저장하고 있는 디렉터리)
/usr 유저 일반 사용자들이 사용하는 디렉터리
/var 바 시스템 운영 중 생성되었다가 삭제되는 데이터를 임시 저장하기 위한 공간으로 사용되는 디렉터리

22. DNS ZONE 파일 설정

레코드 설명
SOA(Start Of Authority) 해당 도메인에 대하여 설정된 네임서버가 모든 정보를 가지고 있음을 선언
Serial 보통 날짜 형식(YYYYMMDD) - 2차 네임 서버와의 연동에 관련된 값
Refresh 2차 네임 서버가 1차 네임 서버로부터 데이터를 가져온 후 다시 업데이트하기 위해 기다리는 시간
Retry 2차 네임 서버가 1차 네임 서버로 접속을 실패하였을 경우 지정된 시간이 지난 후 다시 재접속하는 시간
Expire 1차 네임 서버에서 받아온 도메인 정보를 보관하는 주기로 지정된 시간이 지나면 받아온 데이터는 신뢰성이 없다고 판단하고 삭제
Minimum TTL(Time To Live) - 도메인 정보를 얼마나 보관할 지에 대한 시간
NS 해당 도메인의 네임서버 지정
A 해당 도메인의 실제 IP주소를 설정
MX(Mail eXchanger) 해당 도메인의 메일서버 지정
CNAME "Canonical NAME" - 특정 도메인에 대한 서브 도메인을 사용하기 위한 레코드
PTR IP주소에 대해 도메인명을 매핑 - Reverse Zone파일에서 사용
AAAA IPv6주소에서 사용되는 A레코드

$TTL – SOA 레코드의 Minimum과 같은 의미 (Minimum 값보다 우선)

24. Syslog Priority Level

emerg = 0 … debug = 7 로 번호가 매겨집니다.

Priority Level 심각도 설명
emerg 긴급 시스템이 사용 불가능한 상태 (즉각조치 필요)
alert 경고 즉각적인 조치가 필요한 상황
crit 치명적 심각한 상황이지만 시스템 전체에는 영향이 없는 경우
err 오류 일반적인 오류 발생 (파일 접근 실패)
warning 경고 위험은 아니지만 주의가 필요한 상태
notice 주목 정상 동작 중이지만 중요한 이벤트 (구성 변경)
info 정보 정보 제공용 메시지 (서비스 시작/종료)
debug 디버그 문제 해결을 위해 추가 정보 제공 (내부 상태, 변수 값 출력)

이어서 rsyslog / loganalyzer 구축 실습과 Windows Server(web, ftp, dns 및 기본 설정) 으로 넘어갑니다.
