## 플랫폼 정책

GitHub Markdown과 Notion native 페이지는 같은 원고·장 순서를 사용합니다. GitHub에는 상대 링크와 Markdown 코드블록을 사용하고, Notion에는 native heading·table·callout·code block으로 변환합니다. HTML 첨부·embed는 사용하지 않습니다.
