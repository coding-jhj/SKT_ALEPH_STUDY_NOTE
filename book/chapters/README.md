# 장 지도

각 장 지도는 원본 본문을 중복 복사하지 않고, 학습 목적과 원문 링크를 제공합니다. 앞 장·목차·다음 장 이동은 [전체 책 목차](../README.md)와 [전체 순서표](../ORDER.md)에서 확인합니다.

> [!NOTE]
> 이 폴더의 Markdown은 `장 지도`와 `원문 보관`을 분리합니다. 장 지도에서 목표·순서를 잡고, 원문에서 실행 명령과 수업 기록을 대조하십시오.

## 이 폴더의 역할

- `01`–`29`: 전체 학습 과정의 장 지도
- `SOURCES.md`: 네트워크·운영체제·보안 관련 공식 문서와 표준 링크
- `originals/`: 사용자가 제공한 Markdown 5개 원문

장 지도에서 원문을 열고, 필요한 경우 원문 보관본과 대조합니다. Notion에는 같은 순서로 native page를 만들며 HTML 파일은 첨부하지 않습니다.

> [!TIP]
> GitHub에서 읽기: 저장소 첫 화면의 부별 목차 → 이 폴더의 장 지도 → `notes/`·`slides/` 원문 → HTML의 검색·소제목 이동 순서가 가장 안정적입니다.
