# 용어집

노트에 반복해서 나오는 용어만 모았습니다. 헷갈리기 쉬운 **짝**을 나란히 두었습니다.
정의는 각 도구의 공식 문서(man 페이지, RHEL/Rocky 문서, Cisco IOS 설정 가이드, MariaDB KB)를 따릅니다.

## 네트워크

**AS (Autonomous System)**
하나의 라우팅 정책 아래 묶인 네트워크 집합. EIGRP에서 `router eigrp 100`의 `100`이 AS 번호이며,
**AS 번호가 다르면 서로 라우팅 정보를 주고받지 않습니다.** 이때 필요한 것이 재분배입니다.

**재분배 (Redistribution)**
서로 다른 라우팅 프로토콜(예: OSPF ↔ EIGRP) 사이에 경로를 옮겨 주는 설정.
양쪽에서 서로 재분배하면 같은 네트워크가 두 경로로 광고되어 루프가 생길 수 있습니다.

**DR / BDR**
브로드캐스트 구간(이더넷)에서 OSPF 이웃 관계를 줄이기 위해 뽑는 대표 라우터와 예비 라우터.
**시리얼 같은 Point-to-Point 구간에서는 뽑지 않습니다.**

**Router ID**
OSPF가 라우터를 식별하는 32비트 값. 지정하지 않으면 가장 큰 Loopback 주소, 그것도 없으면
가장 큰 물리 인터페이스 주소가 됩니다. 이미 정해진 뒤에는 `clear ip ospf process`를 해야 바뀝니다.

**표준 ACL vs 확장 ACL**

| | 표준 | 확장 |
|---|---|---|
| 번호 | 1–99, 1300–1999 | 100–199, 2000–2699 |
| 판단 기준 | **출발지 IP만** | 출발지·목적지 IP + 프로토콜 + 포트 |
| 두는 위치 | 목적지에 **가깝게** | 출발지에 **가깝게** |

이유: 표준 ACL은 목적지를 못 보므로 출발지 근처에 두면 정상 트래픽까지 막습니다.

**암묵적 거부 (implicit deny)**
모든 ACL 끝에는 보이지 않는 `deny any`가 있습니다. 한 줄이라도 `permit`이 없으면 전부 막힙니다.

**inbound / outbound**
ACL을 인터페이스에 걸 때의 방향. **라우터를 기준으로** 들어오는 트래픽이 inbound,
라우터에서 나가는 트래픽이 outbound입니다. 어느 쪽에 걸지가 곧 어느 지점에서 걸러지느냐입니다.

**NAT / PAT**
사설 주소를 공인 주소로 바꾸는 것이 NAT. 포트 번호까지 함께 바꿔서 여러 사설 주소가
**공인 주소 하나를 공유**하게 하는 것이 PAT(= NAT Overload).

**정적 NAT (Static NAT)**
사설 주소 하나를 공인 주소 하나에 **고정 매핑**. 외부에서 내부 서버로 들어와야 할 때 씁니다.

**IPSec**
IP 계층에서 암호화·인증을 수행하는 표준 묶음. VPN 터널의 실제 보호를 담당합니다.

**GRE 터널**
IP 위에 또 다른 IP 패킷을 실어 나르는 캡슐화. 자체 암호화는 **없습니다** — 보호가 필요하면
IPSec과 함께 씁니다.

**HSRP**
게이트웨이를 이중화하는 시스코 프로토콜(FHRP의 하나). 여러 라우터가 가상 IP 하나를 공유하고,
활성 라우터가 죽으면 대기 라우터가 받습니다.

## 리눅스 서버

**systemctl `start` vs `enable`**
`start`는 **지금 한 번** 켜는 것, `enable`은 **부팅할 때 자동으로** 켜지게 등록하는 것.
둘은 별개라 `start`만 하면 재부팅 후 꺼져 있습니다. `enable --now`가 둘을 동시에 합니다.

**`reload` vs `restart`**
`reload`는 프로세스를 유지한 채 설정만 다시 읽습니다. `restart`는 죽였다 다시 띄웁니다.
연결이 끊기면 곤란한 서비스는 `reload`를 먼저 시도합니다.

**SELinux**
프로세스와 파일에 **라벨**을 붙이고 정책으로 접근을 통제하는 커널 보안 모듈.
파일 권한(`rwx`)이 맞아도 라벨이 안 맞으면 막힙니다. 이때 권한을 아무리 고쳐도 해결되지 않습니다.

| 모드 | 뜻 |
|---|---|
| `Enforcing` | 정책 위반을 **차단**하고 기록 |
| `Permissive` | 차단하지 않고 **기록만** — 원인 파악용 |
| `Disabled` | 아예 끔. RHEL 9부터는 커널 파라미터로만 완전 비활성화 |

**컨텍스트 (context)**
SELinux 라벨. `ls -Z`로 봅니다. 웹 문서라면 보통 `httpd_sys_content_t`입니다.
`chcon`은 임시, **`semanage fcontext` + `restorecon`이 영구**입니다.

**부울 (boolean)**
정책 안에서 켜고 끄는 스위치. 예: `setsebool -P httpd_can_network_connect_db on`.
SELinux를 끄지 않고 필요한 동작만 열어 주는 정석입니다.

**NFS vs Samba**

| | NFS | Samba |
|---|---|---|
| 주 대상 | 리눅스 ↔ 리눅스 | 리눅스 ↔ 윈도우 |
| 프로토콜 | NFS (RPC 기반) | SMB/CIFS |
| 인증 | 기본은 호스트/UID 기반 | 사용자 계정 기반 (`smbpasswd`) |

**`/etc/exports`**
NFS가 무엇을 누구에게 어떤 조건으로 내보낼지 적는 파일. 고친 뒤 `exportfs -ra`로 적용합니다.

**마운트 (mount) / 영구 마운트**
원격 공유를 로컬 디렉터리에 붙이는 것. `mount` 명령은 **재부팅하면 사라집니다.**
계속 쓰려면 `/etc/fstab`에 적어야 합니다.

**rsyslog**
로그를 받고 걸러 내보내는 데몬. 입력 모듈(`im*`)로 받고 출력 모듈(`om*`)로 내보냅니다.
로그를 다른 서버로 모으는 **중앙 수집**의 기본 도구입니다.

**Facility / Priority**
syslog가 로그를 분류하는 두 축. Facility는 **어디서** 났는지(`auth`, `cron`, `mail`…),
Priority는 **얼마나 급한지**(`emerg` … `debug`)입니다.

**umask**
새로 만드는 파일의 권한에서 **빼는** 값. `umask 022`면 디렉터리는 `755`, 파일은 `644`가 됩니다.

**`/proc`**
커널이 자기 상태를 파일처럼 보여 주는 가상 파일시스템. 디스크에 실제 파일이 있는 게 아닙니다.
`/proc/meminfo`, `/proc/cpuinfo`가 대표적입니다.

**`sysctl`**
`/proc/sys` 아래 커널 파라미터를 읽고 바꾸는 명령. **명령으로 바꾼 값은 재부팅하면 사라집니다.**
영구히 두려면 `/etc/sysctl.d/*.conf`에 적습니다.

**`vm.swappiness`**
메모리가 빠듯할 때 스왑을 얼마나 적극적으로 쓸지 정하는 값(0–100). 낮을수록 스왑을 덜 씁니다.

**available (free 명령의 열)**
"스왑 없이 새 프로그램에 당장 내줄 수 있는 메모리" 추정치. `free` 열 중 **실제로 봐야 할 값**입니다.
`free`(비어 있음) 열이 작다고 메모리가 부족한 것이 아닙니다 — 캐시로 쓰고 있을 뿐입니다.

## 데이터베이스 (MariaDB)

**계정은 `'이름'@'호스트'`**
MariaDB 계정의 식별자는 이름만이 아닙니다. `test@localhost`와 `test@'192.168.16.%'`는
**서로 다른 계정**입니다. `DROP USER test`는 `test@'%'`를 지웁니다.

**`localhost` vs `127.0.0.1`**
MariaDB 클라이언트에서 `localhost`는 **유닉스 소켓**으로, `127.0.0.1`은 **TCP**로 붙습니다.
접속 경로가 다르므로 권한 판정에 쓰이는 계정 행도 달라질 수 있습니다.

**문자셋 (charset) / 콜레이션 (collation)**
charset은 문자를 바이트로 저장하는 방식, collation은 그 문자들의 **정렬·비교 규칙**입니다.
한글이 깨지면 서버·DB·테이블·연결 중 어느 층의 charset이 어긋났는지 봐야 합니다.

**논리 백업 (logical backup)**
`mariadb-dump`처럼 **SQL 문장으로** 뽑는 백업. 사람이 읽을 수 있고 버전 간 이식이 쉽지만
복원이 느립니다. 파일을 통째로 복사하는 물리 백업과 대비됩니다.

**복제 (replication)**
Primary의 변경을 Replica가 따라 적용하는 것. **백업이 아닙니다** —
Primary에서 지운 데이터는 Replica에서도 지워집니다.

**PDO / DSN**
PDO는 PHP의 DB 접근 계층, DSN은 "어느 드라이버로 어느 호스트의 어느 DB에 붙을지"를 적은 문자열입니다.

**prepared statement**
SQL 뼈대와 값을 **분리해서** 보내는 방식. 값이 SQL 문법으로 해석되지 않으므로
SQL Injection을 구조적으로 막습니다. 문자열을 이어 붙여 쿼리를 만들면 안 되는 이유입니다.

**VIEW**
저장된 SELECT 문. 실제 데이터를 갖지 않고 조회할 때마다 원본 테이블을 읽습니다.
원본 테이블이 없으면 `ERROR 1146`이 납니다.

## 자주 틀리는 짝 정리

| 헷갈리는 것 | 차이 |
|---|---|
| `systemctl start` / `enable` | 지금 켜기 / 부팅 시 켜기 |
| `reload` / `restart` | 설정만 다시 읽기 / 프로세스 재시작 |
| `chcon` / `semanage fcontext` | 임시 라벨 / 영구 라벨 |
| `mount` / `/etc/fstab` | 지금만 / 재부팅 후에도 |
| `sysctl -w` / `/etc/sysctl.d/` | 지금만 / 재부팅 후에도 |
| 표준 ACL / 확장 ACL | 출발지만 / 출발지+목적지+포트 |
| 백업 / 복제 | 과거 시점 보존 / 현재 상태 동기화 |
| NAT / PAT | 1:1 주소 변환 / 포트까지 써서 N:1 |
| `localhost` / `127.0.0.1` (MariaDB) | 유닉스 소켓 / TCP |

같은 패턴이 반복됩니다. **"지금만 적용되는 명령"과 "재부팅 후에도 남는 파일"이 항상 따로 있습니다.**
실습에서 되던 것이 재부팅 후 안 되면 거의 이 구분을 놓친 것입니다.
