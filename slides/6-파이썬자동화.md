### 8. 사용자 계정 필터링 및 CSV 생성 스크립트

# 내부 라이브러리 임포트 import csv input_file = '/etc/passwd' out_file = './login_users_report.csv' login_users = []  # 로그인 가능한 계정 저장 리스트 with open(input_file, 'r') as f: for line in f: # 빈 줄 또는 주석 건너뜀 if line.startswith('#') or not line.strip(): continue # 콜론(:)을 기준으로 필드 분리 (awk -F ':' 와 동일) parts = line.strip().split(':')

# 리스트 인덱스: 0=사용자명, 2=uid, 5=홈디렉토리, 6=로그 인셸 username = parts[0] uid = parts[2]        # 세 번째 필드 → 리스트 인덱스 2 home_dir = parts[5] login_shell = parts[6]

# /bin/bash 또는 /bin/sh 셸을 가진 계정만 필터링 if '/bash' in login_shell or '/sh' in login_shell: login_users.append([username, uid, home_dir, lo gin_shell])

# csv 모듈의 writer 함수로 CSV 파일 저장 with open(out_file, 'w') as f: writer = csv.writer(f) writer.writerows(login_users)

split(':')  함수는 셸 스크립트의 awk -F ':' 와 동일하게 콜론을 기준으로 문자열을 분 리한다. 파이썬 리스트는 0부터 인덱스가 시작하므로 세 번째 필드(uid)는 인덱스 2가 된 다.

### 4. 메모장 프로그램 구현

#### 4-1. 전체 구조 개요

실제 Windows 메모장을 참고하여 구현할 항목은 다음과 같다.


| 구성 요소 | 설명 |
|---|---|
| 창 제목 | 상단에 프로그램 이름 표시 |
| 메뉴 바 | 파일, 편집, 서식, 보기, 도움말 메뉴 |
| 스크롤바 | 내용이 많아질 경우 스크롤 지원 |
| 텍스트 영역 | 글자를 입력할 수 있는 본문 영역 |

#### 4-2. 메뉴 바 구성

import os from tkinter import * root = Tk() root.title('윈도우즈 메모장') root.geometry('640x480')

# 전체 메뉴 바 생성 menu = Menu(root)

# 파일 메뉴 항목 생성 (tearoff=0: 메뉴 분리 비활성화) menu_file = Menu(menu, tearoff=0)

# 파일 메뉴에 항목 추가 menu_file.add_command(label='열기', command=open_file) menu_file.add_command(label='저장', command=save_file) menu_file.add_separator()                               # 구분선 추가 menu_file.add_command(label='끝내기', command=root.quit)

# 메뉴 바에 파일 메뉴를 캐스케이드(하위 메뉴)로 등록 menu.add_cascade(label='파일', menu=menu_file)

# 메뉴 바 적용 root.config(menu=menu)

메뉴 구성 방식:


| 함수 | 역할 |
|---|---|
| Menu(root) | 전체 메뉴 바 생성 |
| Menu(menu, tearoff=0) | 특정 메뉴 항목 생성 |
| add command(label='이름', command=함수)<br>_ | 클릭 시 실행할 명령어가 있는 항목 추가 |
| add separator()<br>_ | 메뉴 항목 사이에 구분선 추가 |
| add cascade(label='이름', menu=메뉴변수)<br>_ | 상위 메뉴에 하위 메뉴 연결 |
| root.config(menu=menu) | 창에 메뉴 바 적용 |

command=root.quit 은 Tkinter에서 기본으로 제공하는 창 종료 함수이므로 별도 정의가 필 요 없다.

⚠️ command 에 지정한 함수가 코드에 정의되어 있지 않으면 실행 시 오류가 발생한다. 인 터프리트 언어이므로 함수는 사용하기 전에 먼저 정의해야 한다.

### 2. 파이썬 가상 환경 (Virtual Environment)

#### 2-1. 가상 환경이 필요한 이유

가상 환경이란 독립된 파이썬 실행 환경으로, 해당 환경 내에서만 작업이 이루어지고 외부 환경에는 영향을 주지 않는다.

가상 환경이 필요한 이유는 다음과 같다.


| 문제 상황 | 설명 |
|---|---|
| 버전 호환성 | Ubuntu 24.04에는 파이썬 3.12가 기본 설치되<br>어 있으나, 프로젝트에 따라 다른 버전이 필요할<br>수 있다 |
| 두 개 이상의 프로젝트 운용 | 프로젝트별로 서로 다른 파이썬 버전이나 라이브<br>러리가 필요한 경우 충돌이 발생할 수 있다 |
| 운영체제 영향 방지 | 가상 환경 없이 패키지를 설치·삭제하면 실제 우분<br>투 운영체제에 영향을 줄 수 있다 |

가상 환경을 사용하면 각 환경이 독립적으로 동작하므로, 다른 환경에 영향을 미치지 않 는다.

#### 2-2. 가상 환경 디렉토리 구조

가상 환경 생성 후 디렉토리 구조는 다음과 같다.

~/ └── python_practice/        # 실습 디렉토리 └── venv/               # 가상 환경 디렉토리 ├── bin/            # 실행 파일 (python3, python3.12, pip, pip3, pip3.12) └── lib/            # 라이브러리 저장소 bin/  디렉토리: 파이썬 실행 명령어 위치 lib/  디렉토리: 설치된 라이브러리 파일 저장

### 3. 가상 환경 설정 실습

#### 3-1. 실습 디렉토리 생성

# 실습용 디렉토리 생성 mkdir python_practice # 디렉토리 목록 확인 ls # 실습 디렉토리로 이동 cd python_practice # 숨김 파일 포함 목록 확인 (아무것도 없는 상태) ls -a

#### 3-2. 가상 환경 생성

# 가상 환경 생성 시도 (venv 모듈이 없을 경우 오류 발생) python3 -m venv venv ⚠️ venv 모듈이 설치되어 있지 않으면 오류 메시지가 나타난다. 이 경우 먼저 venv 도구 를 설치해야 한다.

# venv 도구 설치 sudo apt install python3-venv # 설치 후 가상 환경 재생성 python3 -m venv venv # 생성 확인 ls ls venv/ 명령어에서 -m venv  의 의미:

v : virtual (가상)

env  / venv : environment (환경)

#### 3-3. 가상 환경 활성화

# 가상 환경 활성화 (source 명령어 사용) source venv/bin/activate 활성화 후에는 프롬프트 앞에 (venv) 와 같이 가상 환경 이름이 표시된다.

가상 환경이 생성되었다고 해서 자동으로 활성화되는 것은 아니다. 반드시 source  명령 어로 활성화해야 한다.

#### 3-4. pip 설치 및 가상 환경 연결 확인

# pip 위치 확인 which pip


| which pip 결과 | 의미 |
|---|---|
| /usr/bin/pip | 가상 환경이 제대로 연결되지 않은 상태 |
| ~/python practice/venv/bin/pip<br>_ | 가상 환경에서 정상 실행 중인 상태 |
